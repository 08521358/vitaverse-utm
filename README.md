# UTM 連結產生器

VitaVerse 維他宇宙行銷團隊用的追蹤連結產生工具。選好用途，自動產生符合公司 UTM 命名規範的連結。

**線上使用：** https://08521358.github.io/vitaverse-utm/

---

## 這是什麼

所有導向官網的站外連結都需要標記來源，GA4 才分得出流量是哪個管道、哪一檔活動帶來的。

手動拼網址容易出錯——大小寫寫錯、medium 寫成 `social` 還是 `paid_social` 搞混、中文變亂碼。這個工具把固定值寫死在程式裡，同事只要點選用途就好。

## 怎麼用

1. **用在哪裡** — Meta 廣告 / FB 粉專 / IG / LINE / EDM / 新聞稿 / KOL
2. **哪一檔活動** — 從已登錄的檔期代碼挑，或自訂新檔期
3. **這是哪一篇（可不填）** — 同一檔活動發了好幾篇時，給每篇一個英文小名
4. **導去哪一頁** — 官網全部 29 頁可選（商品、分類、優惠、品牌、專欄文章、客服），或貼自訂網址

右邊會即時產生結果，按「複製」就能用。

## 工具會自動幫你擋掉的錯誤

- 輸入中文或空格 → 提示並自動轉換
- 落地頁網址已含 `utm_` → 警告（Shopify 的「複製連結」按鈕會偷加 `copyToPasteBoard`）
- 選到 Google Ads → 提示不需要掛（Google 用 gclid 自動辨識）
- 選到站內連結 → 擋下（會切斷工作階段）

## 重要分別

| 用途 | utm_medium |
|---|---|
| 有花錢的廣告 | `paid_social` |
| 粉專自然發文 | `social` |

差一個字，在 GA4 是兩個完全不同的管道。寫錯會讓廣告成效被免費流量灌水。

## 新增檔期或管道

固定值寫在 `index.html` 最下方的 `CHANNELS`、`CAMPAIGNS`、`PAGES` 三個清單裡。

**請先更新《UTM 命名規範》文件，再來改這裡**，避免兩邊對不起來。

```js
var CAMPAIGNS = [
  {code:'newopen_2610', label:'官網開幕慶 NEW OPEN · 2026-10 起'},
  // 新檔期加在這裡
];
```

## 技術

單一 HTML 檔，沒有相依套件、沒有後端、不蒐集任何資料。所有運算都在瀏覽器裡完成。

直接開檔案也能用，不一定要透過網站。
